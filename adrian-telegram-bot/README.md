# Эдриан 2.0 — личный Telegram-бот

Рабочая версия 2.0 на Cloudflare Workers. GitHub хранит исходники; Cloudflare запускает код без отдельного VPS (в пределах доступных тарифных квот). Сайт в корне репозитория не затронут.

**Это отдельный ИИ-помощник с ролью Эдриана, а не подключение этого чата GPT-6 и его памяти.** ChatGPT Plus не включает оплату OpenAI API.

## Возможности

- Текстовый и голосовой русский язык через Workers AI и Whisper.
- ИИ-планирование поручений и проверка входных данных перед действиями.
- Задачи Todoist: создание, просмотр, недельные и дневные сводки, поиск, перенос, завершение и удаление с подтверждением.
- Напоминания Todoist push по явному поручению, с проверкой результата.
- Заметки и память в Cloudflare KV, доступ только владельцу.
- Защита Telegram ID, секрет webhook, строгий набор допустимых действий.

Ниже сохранены инструкции первичной установки. Полный список новых команд, ограничений и обновления webhook — в разделе «Эдриан 2.0: текущая функциональность».

## 1. Создать бота в Telegram

Открой @BotFather в Telegram, отправь /newbot, укажи имя «Эдриан» и свободное имя пользователя, заканчивающееся на bot. BotFather выдаст TELEGRAM_BOT_TOKEN. **Не отправляй токен в чат и не выкладывай в GitHub.**

## 2. Подключить Cloudflare

1. Открой https://dash.cloudflare.com/ и создай бесплатный аккаунт.
2. Workers & Pages → Create application → GitHub (Import a repository).
3. Подключи репозиторий itman365/admin.
4. Укажи **Root directory: adrian-telegram-bot**. Это важно: в корне другого сайта нет конфигурации воркера.
5. Build command оставь пустым; Deploy command: npx wrangler deploy; Worker name: adrian-telegram-bot.
6. Deploy. Получишь адрес вида https://adrian-telegram-bot.<subdomain>.workers.dev
7. Проверь GET https://адрес-воркера/health — ответ должен содержать ok:true.

Альтернатива из локального терминала внутри папки: npm install; npx wrangler login; npm run deploy.

## 3. Задать секреты

В Cloudflare: Worker → Settings → Variables and Secrets (Runtime):

| Имя | Содержимое | Тип |
|---|---|---|
| TELEGRAM_BOT_TOKEN | Токен от @BotFather | Secret |
| TELEGRAM_WEBHOOK_SECRET | Случайная строка 32–64 символа A–Z, a–z, 0–9, _ или - | Secret |
| OWNER_TELEGRAM_ID | Твой цифровой Telegram ID | Secret или Text |
| TODOIST_API_TOKEN | Todoist Settings → Integrations → Developer → API token | Secret |
| TODOIST_PROJECT_ID | ID личного проекта «Эдриан» | Text |

OWNER_TELEGRAM_ID можно установить после /id в пункте 5. Для обычного общения Todoist-переменные не обязательны.

**Никаких токенов и секретов в GitHub. Репозиторий публичный.**

## 4. Зарегистрировать Telegram webhook

После добавления обязательных Telegram-секретов открой PowerShell на своём компьютере и выполни:

~~~powershell
$worker = (Read-Host "Полный URL воркера, без / в конце").TrimEnd('/')
$secret = Read-Host "Значение TELEGRAM_WEBHOOK_SECRET"
Invoke-RestMethod -Method Post -Uri "$worker/setup" -Headers @{ Authorization = "Bearer $secret" }
~~~

Успех: JSON с ok:true и адресом /webhook. Секрет не вводится в браузерную строку и не записывается в исходники. POST /setup принимает только значение секретного Authorization header; обычный GET не выполнит настройку.

## 5. Узнать Telegram ID

Открой нового бота в Telegram и отправь /id. Он ответит числом. Добавь это число в Cloudflare как OWNER_TELEGRAM_ID. Затем напиши /start. Все другие пользователи будут заблокированы.

## 6. Todoist

Укажи TODOIST_API_TOKEN из личного Todoist, а TODOIST_PROJECT_ID — ID существующего проекта «Эдриан». Если ID проекта не задан, задача попадёт во «Входящие».

Примеры:

- /task Проверить рекламные кампании
- /task завтра в 10:00 | Позвонить Андрею
- задача: подготовить смету
- Голосовое «Задача: проверить остатки по складу».

Формат срока: сначала срок, затем символ |, затем название задачи. В голосовых с датами этот разделитель может распознаваться неточно; текст надёжнее.

## 7. Необязательная память

Без KV бот отвечает на каждое сообщение независимо. Чтобы включить память последних сообщений:

1. В Cloudflare Workers KV создай namespace ADRIAN_HISTORY и скопируй его ID.
2. В wrangler.toml сними комментарии с блока kv_namespaces и поставь ID вместо REPLACE_WITH_YOUR_KV_NAMESPACE_ID.
3. Закоммить изменение в GitHub; Worker автоматически обновится.

В этом KV хранится только короткая история из Telegram; к памяти ChatGPT она не подключается. /reset сбрасывает её. KV дополнительно помогает отсекать повторную доставку сообщений Telegram, но не предоставляет строгую транзакционную гарантию.

## Проверка и ограничения

- /health означает, что код развернут, но не подтверждает Telegram, AI или Todoist.
- Бот не отвечает на /id: проверь выполнение /setup, токены и Cloudflare Worker logs.
- 403 на /setup: неправильный секрет webhook.
- Ошибки модели: проверь AI binding, лимит бесплатных Neurons и logs.
- Todoist 401: неверный API токен. Todoist 400: срок или проект.
- Бесплатная квота AI ограничена; 24/7 относится к доступности инфраструктуры, а не гарантии бесперебойности.
- Нет автономных напоминаний, мониторинга и синхронизации с этим чатом.
- Вход в Cloudflare из России может зависеть от сети и региональных правил.

Тесты: npm test. Для локального деплоя: npm run deploy.

## Если Cloudflare Retry build использует старый KV ID

Retry build может повторно запускать предыдущую версию репозитория. Проверь, что **новая сборка** использует последний коммит GitHub, а в ее логе в разделе Bindings указан существующий KV namespace. Нажимать Retry на старом ошибочном запуске не нужно. Последняя проверенная конфигурация находится в `wrangler.toml`.


## Эдриан 2.0: текущая функциональность (ноябрь 2026)

Рабочее ядро: Telegram + Cloudflare Workers AI + Todoist + Cloudflare KV.
Это отдельный бот, а не этот чат GPT-6 и его память. ChatGPT Plus не включает инфраструктуру API.

**Умеет:** голосовые и текстовые сообщения; разбор поручений в структурированный JSON; создание задач с датами по Москве; отдельные push-напоминания; просмотр задач на сегодня; сводки о просроченных; перенос, закрытие и удаление задач; заметки в KV, доступные в диалоге; список проектов; проверку ответов Todoist.

**Безопасность:** завершение и удаление задач требуют подтверждения кнопкой или /confirm. Отмена — /cancel. Если дата, время или задача неоднозначны, бот сообщает об этом вместо ложного «готово». Секреты должны быть только в Cloudflare Runtime Secrets.

| Команда | Действие |
| --- | --- |
| /tasks | Активные задачи проекта «Эдриан» |
| /today | Задачи на сегодня |
| /digest | Сегодня и просроченные по проектам |
| /projects | Проекты Todoist |
| /done ID | Отметить выполненным после подтверждения |
| /delete ID | Удалить после подтверждения |
| /move ID \| завтра в 11:00 | Перенести задачу |
| /confirm | Подтвердить ожидаемое действие |
| /cancel | Отменить |
| /note текст | Сохранить заметку |
| /notes | Список заметок |
| /status | Показать настройки (без обращения к API) |
| /check | Проверить реальный ответ Todoist и доступность памяти |
| /last | Последняя подтверждённая созданная задача |

Обычным языком: «Напомни завтра в 12:30 оплатить дороги», «Поставь задачу на субботу закрыть подвал», «Перенеси задачу купить саморезы на 11 часов». Для сохранения заметки: «Эдриан, запомни: ...». Для обсуждения маркетинга и подготовки текстов используй обычный чат.

**Развертывание:** GitHub main → Cloudflare Deployments, обязательно проверь последний коммит и Success. В публичном адресе Worker запрос /health должен показывать version: 2.0.0.

После обновления старого webhook нужно повторно вызвать POST /setup с заголовком Authorization: Bearer и значением TELEGRAM_WEBHOOK_SECRET, чтобы включить callback_query для кнопок. Без кнопок подтверждение работает через /confirm.

**Ограничения:** не подключены Gmail, Calendar, внешние сайты, социальные сети и локальный компьютер; они требуют отдельной авторизации и программных модулей. Push Todoist не является будильником. AI и Cloudflare имеют квоты. Проверяй дату и название перед тем, как полагаться на поручение. KV не гарантирует строго однократного исполнения.

Если Telegram Bot Token или webhook secret фигурировал в чате, перевыпусти секреты и обнови их в Cloudflare. Не пересылай их сюда и не сохраняй в GitHub.

Исходники v2: src/task-engine.js, src/todoist-api.js, src/agent-router.js. Проверка: npm test.

## Дополнительная надёжность (2.0.1)

Перед созданием через новый обработчик голосовых запросов бот проверяет Todoist на идентичную задачу с тем же сроком, созданную за последние 10 минут. При совпадении не дублирует её, а показывает ID. Для этой проверки нужен KV binding HISTORY и доступ к чтению Todoist. Это эвристическая защита, не транзакционная гарантия: Cloudflare KV обладает eventual consistency, а старый резервный обработчик /task может не использовать эту проверку.

Команда /check делает реальный запрос на чтение задач в Todoist и проверяет доступность KV; наличие AI binding она показывает отдельно, без тестового запроса к модели. Команда /last хранит последнее подтверждение создания в KV на 14 дней, не заменяя журнал Todoist.


## Эдриан 2.1 — Gemini Free + Workers AI (ноябрь 2026)

В этой версии Gemini API — **дополнительный источник** ответов и JSON-планирования. Если GEMINI_API_KEY отсутствует или Gemini отвечает ошибкой/исчерпал квоту, бот автоматически использует существующий Workers AI. Для голосовых сообщений остаётся Workers AI Whisper. Задачи создаются и проверяются отдельно через Todoist.

**Бесплатный режим:** проект Google AI Studio ADRIAN-AI-SYSTEM должен оставаться на **Free tier**, без включения Billing. Конкретные квоты и доступность моделей могут меняться; проверяйте Rate limit в AI Studio. ChatGPT Plus и Gemini Pro не оплачивают Gemini API автоматически.

1. Google AI Studio → API Keys → создайте отдельный ключ для Cloudflare, не публикуйте его в чате или коде.
2. Cloudflare → Workers & Pages → adrian-telegram-bot → Settings → Variables and Secrets → Add Secret, имя `GEMINI_API_KEY`, значение — новый ключ, тип — **Secret**.
3. Переменная `GEMINI_MODEL` задаётся в `wrangler.toml` (начальный вариант `gemini-3.5-flash-lite`). Менять модель только после сверки с фактически доступной на бесплатном тарифе.
4. После развёртывания: `/health` должен показывать версию 2.1.0, Telegram `/status` — наличие Gemini key, `/check` — доступность Todoist и KV.
5. Проверьте сообщение без изменения данных и отдельно безопасную тестовую задачу. Ответ `/status` показывает конфигурацию, но **не гарантирует** успешную генерацию Gemini.

**Проверки:** `node --test`, включая модельную маршрутизацию, отказ из-за квоты, ограничения на повторяющиеся поручения и контроль ошибочных дат.

**Безопасность:** ранее показанные кому-либо API-ключи перевыпускайте. Runtime Secrets не должны попадать в GitHub, frontend, логи, скриншоты и сообщения. Важные операции Todoist требуют подтверждённого ответа API. Лимиты бесплатных ресурсов не гарантируют непрерывную работу.

Версия 2.1 не превращает отдельный Worker в ChatGPT с его памятью и не подключает автоматически Gmail, Instagram или другие сервисы.
